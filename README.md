# GameSpecAI

Este é um sistema desenvolvido para gerenciar uma lista de jogos e utilizar Inteligência artificial para recomendar os requisitos de hardware para rodá-los.

# Contexto:

Um usuário deseja jogar um título novo, mas não sabe se seu computador possui hardware suficiente para rodá-lo. Normalmente, ele precisaria abrir diversos sites, pesquisar requisitos mínimos e recomendados, comparar informações e verificar a compatibilidade com seu PC.

Com o GameSpecAI, esse processo é facilitado. O usuário apenas informa o nome do jogo desejado e o sistema utiliza Inteligência Artificial para buscar e apresentar os requisitos de hardware recomendados de forma rápida e organizada.


## O usuário pode:
- Organizar uma lista de jogos de interesse.
- Consultar requisitos de hardware sem precisar pesquisar manualmente na internet.
- Planejar upgrades no computador.
- Verificar se seu PC é compatível com determinados jogos.

## Funcionalidades:
- Adicionar jogos da lista.
- Remover jogos da lista.
- Visualizar todos os jogos.
- Receber recomendações de hardware usando IA.
- Armazenamento dos jogos em array/vetor.
